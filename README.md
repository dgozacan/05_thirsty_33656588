# Thirsty Student Shop - Pirate Bay Alcohol

A web application for a drinks shop built with Node.js, Express, and EJS.

## Features
- Dynamic homepage showing product categories
- About page with multiple shop locations
- Search functionality with form validation
- User registration with email validation
- Responsive CSS styling

## Installation

1. Clone the repository:
```bash
   git clone https://github.com/dgozacan/05_thirsty_33656588.git
   cd 05_thirsty_33656588
```

2. Install dependencies:
```bash
   npm install
```

3. Run the application:
```bash
   node index.js
```

4. Visit in browser:
```
   http://localhost:8088/
```


## Routes

- `/` - Homepage 
- `/about` - Shop locations and managers
- `/search` - Search form 
- `/register` - Registration form 

## Technologies Used

- **Node.js** - JavaScript runtime
- **Express** - Web application framework
- **EJS** - Templating engine
- **CSS** - Styling
